# 🐾 **Vila Petshop – Landing Page**

Landing page desenvolvida como parte do **Checkpoint Final da trilha Primeiros Passos – DevMedia**.

🔗 Acesse o site

O projeto está disponível para visualização em:
👉 https://vilapetshop.vercel.app/

## 📌 Sobre o Projeto

Este projeto foi criado para cumprir os requisitos do checkpoint da DevMedia, cujo objetivo é construir uma **landing page simples**, utilizando somente **HTML e CSS**, para um comércio local hipotético.

Escolhi desenvolver a **Vila Petshop**, um lugar acolhedor inspirado no conceito de *vila, lar e natureza*, oferecendo serviços essenciais para pets. O site foi pensado para ser visualmente agradável, funcional e com navegação intuitiva.

---

## 🎯 **Objetivos do Checkpoint**

De acordo com as orientações do curso, este projeto demonstra habilidades de:

✔ Estruturação de páginas utilizando HTML semântico
✔ Estilização com CSS puro
✔ Construção de uma landing page seguindo layout de referência da missão anterior (projeto “Imobiliária”)
✔ Uso de seções bem definidas
✔ Inserção de imagens, navegação interna e mapa embedado
✔ Organização, responsividade básica e boas práticas de código

---

## 📚 **Requisitos Atendidos**

### ✔ Estrutura do site (5 seções obrigatórias)

* **Topo** – logotipo e navegação interna
* **Área principal** – imagem da fachada
* **Serviços** – lista detalhada dos serviços oferecidos
* **Sobre nós** – apresentação e proposta da Vila Petshop
* **Contato** – mapa, telefone e e-mail

### ✔ Outras exigências

* Logomarca no topo
* Cores alternadas entre as seções
* Google Maps incorporado
* Estrutura semelhante ao projeto “Imobiliária”
* Imagens inseridas nas seções "Área principal" e "Sobre nós"
